# 온톨로지 실전 입문

> Neo4j와 AI로 지식그래프 시스템 만들기

온톨로지 기초부터 Neo4j 지식그래프 구축, 그래프 알고리즘(GDS), GraphRAG까지 — **HR안내봇**이라는 하나의 관통 프로젝트를 1장에서 시작해 11장에서 완성하는 실전형 기술서입니다.

## 읽기

- **웹 버전**: [GitHub Pages에서 읽기](https://ksangki.github.io/ontology-neo4j-ai/)
- **EPUB**: [`온톨로지-실전-입문-v1.0.0.epub`](온톨로지-실전-입문-v1.0.0.epub) 다운로드
